# CeFaci — „Vineri, 20:30” (video TikTok, v2)

56 secunde, 1080×1920, 30 fps, H.264 + AAC. Ecrane reale din aplicație (versiunea de test, capturate din `mobile/` cu `EXPO_PUBLIC_E2E=1`, ora fixată vineri 20:30), cu numele localurilor blurate. Muzică originală generată din cod (`soundtrack.py`), fără sample-uri, voci sau melodii luate de altundeva.

Randare: `node scripts/render-teaser-v2.mjs` (sau `--stills` pentru cadre de probă) → `release/video/CeFaci-teaser-v2-56s.mp4`.
